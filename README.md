AccessEvent — Инклюзивная платформа мероприятий
Описание проекта
AccessEvent — это специализированная веб-платформа для организации и проведения различных мероприятий с ключевым акцентом на доступность для людей с нарушениями слуха. Наша цель — убрать барьеры в коммуникации и обеспечить полноценный, комфортный доступ к информации о событиях без необходимости использовать слух.

Ключевые возможности платформы
Создание инклюзивных событий: Организаторы могут гибко настраивать параметры доступности, добавлять текстовые описания и специальные теги.
Система визуальных уведомлений: Реализованы всплывающие текстовые баннеры, цветовые маркеры и индикаторы статусов для контроля без звука.
Интерактивное текстовое взаимодействие: Встроенные чаты на страницах мероприятий позволяют участникам общаться с организаторами напрямую в режиме реального времени.
Обратная связь: Возможность оставлять текстовые отзывы для оценки качества проведенных встреч.
Технологический стек
Язык программирования: Python 3.10+
Веб-фреймворк: Flask 2.3+
База данных: PostgreSQL 14+ с использованием SQLAlchemy ORM
Контейнеризация: Docker
