Анализ предметной области: AccessEvent
1. Описание предметной области
AccessEvent — платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха. Платформа решает проблему интеграции глухих и слабослышащих людей в публичные и образовательные события за счет внедрения текстовых и визуальных ассистивных технологий взаимодействия.

2. Сущности и атрибуты
Сущность 1: Event
Сущность	Атрибуты	Описание
Event	id, title, date, location, description, is_inclusive	Мероприятие, создаваемое на инклюзивной платформе
Сущность 2: Participant
Сущность	Атрибуты	Описание
Participant	id, name, email, phone, hearing_status	Участник мероприятия с указанием статуса слуха
Сущность 3: Organizer
Сущность	Атрибуты	Описание
Organizer	id, name, contact, rating	Организатор инклюзивного мероприятия
Сущность 4: Registration
Сущность	Атрибуты	Описание
Registration	id, event_id, participant_id, status, created_at	Запись о регистрации участника на выбранное событие
Сущность 5: Notification
Сущность	Атрибуты	Описание
Notification	id, user_id, type, message, color	Визуальное всплывающее уведомление для пользователя
Сущность 6: Review
Сущность	Атрибуты	Описание
Review	id, event_id, participant_id, rating, text	Текстовый отзыв и оценка мероприятия от участника
3. Бизнес-процессы
3.1. Создание мероприятия
Организатор создает мероприятие, указывая дату, место, описание. Может отметить как инклюзивное.

3.2. Регистрация на мероприятие
Участник находит мероприятие, регистрируется. Статус: ожидание -> одобрено/отклонено.

3.3. Визуальные уведомления
За 30 минут до начала система показывает цветной баннер (зеленый — началось, желтый — скоро, красный — отмена).

3.4. Текстовый чат
Участник пишет в чат на странице мероприятия. Организатор видит и отвечает.

3.5. Отзыв на мероприятие
После завершения участник может оставить отзыв (оценка + текст).

4. Роли пользователей
Организатор — создает и управляет мероприятиями.
Участник — регистрируется и посещает мероприятия.
Администратор — контролирует платформу и модерацию.
Гость — просматривает мероприятия без регистрации.
